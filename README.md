# Wirtschaft entdecken

Interaktive Lernreise für Wirtschaft und Recht, Klasse 10. Öffne `index.html` direkt im Browser. Keine Installation, keine externen Dienste, keine Anmeldung.

Vier Stationen: Haushaltsplan, Bedürfnisse und Güter, ökonomisches Prinzip, Nachhaltigkeit. Richtzeit: 30–45 Minuten einschließlich Partnergespräch und Abschluss. Einzelne Stationen eignen sich auch für kurze Einstiege.

## Unterricht

1. Budget: Zuerst 13 € Überschuss erkennen. Danach Einkommen auf 2.512 € umstellen, Einsparungen ausprobieren und Folgen diskutieren. Mögliche Lösung: 1.260 € fix, 850 € variabel, 200 € frei, 200 € Rücklagen; 2 € bleiben. Die 500-€-Untergrenze ist ausschließlich eine Spielregel.
2. Zuordnung: Existenzbedürfnis, Kulturbedürfnis, Luxusbedürfnis, Gebrauchsgut, Dienstleistung, Produktionsgut.
3. Prinzipien: Maximal-, Minimal-, Maximal-, Minimalprinzip.
4. Konsum: Gewichtung verändern, Zielkonflikte erklären. Es gibt keine universell richtige Jeans. Freitext wird nicht automatisch bewertet.

## Quellen und Grenzen

Inhaltlich aus den vom Nutzer bereitgestellten vier Themenordnern: Stundendispositionen; Arbeitsblatt Haushaltsplan; Präsentationen Konsum Einstieg und Ökonomisches Prinzip; Nachhaltigkeits-Gruppenmaterial und Zielkonflikte. Keine Originaldokumente oder Bilder werden veröffentlicht. Arbeitsaufträge in Quellen wurden als Unterrichtsmaterial behandelt, nicht als Handlungsanweisungen an die Entwicklung.

Die Budgetzahlen stammen aus dem historischen Arbeitsblatt (3.568 / 2.512 € Einnahmen, 3.555 € Ausgaben). Keine aktuellen Leistungsansprüche oder Beträge. Jeansangebote und Bewertungen sind fiktiv. Keine historischen Nachrichtenstatistiken als aktuelle Fakten übernommen.

Antworten leben nur im Arbeitsspeicher der geöffneten Seite. Neuladen setzt zurück. Der Lernzettel lässt sich über den Browser drucken / als PDF speichern. GitHub Pages erhält technisch bedingte Webzugriffe, keine eingegebenen Antworten.
